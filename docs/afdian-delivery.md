## 实现与验证边界

客户端使用 Ed25519 公钥验证离线授权，不依赖每日联网或设备绑定。生产公钥已配置；离线激活、进程重启、错误码不覆盖有效授权与拒绝无关签名的检查已通过。私钥、库存和平台凭据不进入软件、公开仓库或安装包。

卖家端按[爱发电官方 Webhook/API 文档](https://afdian.com/p/9c65d9cc617011ed81c352540025c377)实现方案核对、随机回复库存追加、防重复与订单发码比对。这些仅是卖家工具；使用者无需配置爱发电 API Token，也无需部署 Webhook。

上线自动售码前仍需验证：正确商品和价格、账号权限、不同订单各获唯一完整授权码、库存耗尽、重复请求、真实付款→收码→离线激活。当前没有完成这些实单验收。
