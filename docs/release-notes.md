# DKYJ Director 0.8.0-preview.6 · 2026-09-16

- 默认固定简化白模：人物为球头＋方块身体，纯色区分，无四肢、五官或服装细节。场景保留主要体块、通道和必要陈设；详细建模必须主动开启。
- 欢迎页改为一段描述直接点击“开始建模”，取消四轮填写；旧草稿自动合并。任务由已连接的 Agent 执行，没有内置模型调度。
- 固定默认运镜相机并复用当前录制轨迹，减少不断新增相机造成的控制问题。
- 手机与手柄控制模式分离；手机专用双摇杆界面，保留高低、转向与录制控制。低频设置折叠。
- 修复录制结束、轨迹与导出衔接；镜头与空间视图各为 16:9，可分开导出或上下合并。

## 验证范围

固定人物生成与单描述流程已通过真实 Blender 集成测试；10 项简报/建模测试、网页提交及控制回归通过。前序录制与双路导出已有 Blender 测试记录。此版 Safari 最终页面实机检查因电脑锁屏未完成；iPhone、Windows GPU、PS5 真机全流程仍待用户验证，不视为已验收。

## 下载与升级

macOS Safari / Windows Edge；手机为 iPhone Safari。Lite 与 Pro 共用正常授权安装包，含对应 GPL 源码；需要另装 Blender、Python 3.11+。

升级前保存工程、备份并退出旧 Blender。完整解压新版，迁移 projects/ 和 takes/；不复制旧 runtime/ 与 .venv/。运行新版安装/启动器，并重启 Agent 的 DKYJ MCP 连接。保留室内与蒸汽小船案例，不含私人赛车工程。
