# DKYJ Director 0.7.0-preview.3

新增电脑顶栏与欢迎页「手机连接」入口，支持普通 / HTTPS 二维码、复制链接和证书引导；界面改为中性灰，场景色彩保留。

大开眼界导演台：在本地 Blender 中搭建简模、调整人物关键帧，通过 iPhone Safari 取景和录制摄影机轨迹。

- 欢迎页提供 Blender、Python、Blender MCP 安装引导，以及场景、人数、动作和运镜的对话任务。
- 支持多个独立项目，复用已建场景并继续编辑。
- 镜头和空间视图分别为 16:9，可独立导出或合成上下拼版。
- 内含室内排练、蒸汽小船出舱与飞机掠过两个公开案例，以及示例视频与场景生成脚本。
- 提供 macOS 与 Windows 两个源码安装包，附对应启动入口、双语说明、透明 Logo、开发日志与校验文件。

Desktop: macOS + Safari / Windows 11 + Edge. Phone: iPhone Safari only. Blender and Python are installed separately. This is local software, not a GitHub Pages-hosted rendering service. Your own MCP-capable agent is optional; no hosted AI subscription is bundled.

这是预览版。Mac 后台渲染和源代码检查已有验证；真实 Windows 显卡与 iPhone 全流程仍需更多设备反馈，详见 [检查记录](release-check.md)。
