# 固定白模与单描述建模

欢迎页只需一个描述框：写好场景、人物和动作，点击 **开始建模**。复用哪个项目放在折叠选项里，不用再分四轮填写。旧版四条草稿合并恢复，原始任务仍可读取。

默认预设 `blockout-v1` 固定如下：

- 人物每人仅两个可见网格：低面球头（16 段、8 圈）＋长方体身体，没有四肢、五官、头发、服装或骨骼。每人一个纯色。
- 默认身高 1.75 m，可按角色尺度调整。头直径占身高 24%，身体高 76%、宽 26%、厚 18%。整体平移与转向表达动作，关键帧保留。
- 环境只保留主要空间、通道、地面和必要家具的大体块；同一空间一种颜色。不加装饰、纹理、复杂倒角或密集小物。
- 仅主动打开 **详细建模** 才例外；新任务与刷新均恢复默认简化。描述中出现“细节”等词不会升级档位，也不会新增确认轮次。

外部 Agent 通过 DKYJ MCP 的 `create_blockout_character` 生成固定人物，再用 Blender MCP 给返回的根对象打关键帧。生成工具固定拓扑与比例，不接受四肢或细节选项；提交简化任务完成状态时会验证这些标准人物，发现多余部件会拒绝完成。

完整场景仍由用户连接的 Agent 制作。点击按钮保存并提交任务，状态会从“等待 Agent”变为“制作中”；未连接或未启动 Agent 时不会假装已开始生成。已有精细项目不会被自动删改，需要 Agent 在独立项目里转换。

验证：单次点击提交、重复点击去重、旧草稿合并、详细开关、未连接提示；后端单段完整描述持久化；Blender 实际固定人物数量、比例、纯色、整体关键帧及额外部件检测；生产服务创建任务与人物集成。
