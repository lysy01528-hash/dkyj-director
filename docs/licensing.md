# Lite / Pro 使用说明

Lite 与 Pro 是同一个安装包。macOS 使用 Safari，Windows 使用 Edge，手机只支持 iPhone Safari；安装及 Blender/MCP 配置沿用 README。

| 功能 | Lite 免费预览 | Pro |
| --- | --- | --- |
| 每个项目保存场次 | 3 个 | 不限 |
| 超额场次 | 可临时编辑；手动删旧场次腾位后保存 | 正常保存 |
| 手机触控、体感、键盘录制 | 可用 | 可用 |
| Xbox / PS5 手柄预览运镜 | 可用 | 可用 |
| 手柄录制 | 官方独立 Demo 可试录 | 正式项目可录制 |
| 镜头、空间、合并视频导出 | 带 `DKYJ DIRECTOR · PREVIEW` 水印 | 无水印 |

在顶栏点 **Lite · 预览版** 查看说明、购买入口或输入授权码。购买对应商业大版本的 Pro 后，在运行 Blender 的电脑粘贴授权码，点“离线激活 Pro”。无需重装，无需绑定设备，无需日常联网验证。手机共用电脑的授权状态；普通局域网 HTTP 页面不提交授权码，请用电脑端或已信任的 HTTPS。

从 0.8.0-preview.2 起已配置生产 v1 公钥，可输入作者签发的有效 Pro 码离线激活。商品购买链接尚未配置，购买入口显示未配置；不要向作者主页普通赞助后期待自动获得 Pro。旧 preview.1 安装包不含对应公钥，需要更新程序后激活。

## 三场次怎么用

打开项目库，在“当前项目的场次”输入名称，新场次会复用当前模型与动作。前三个可以保存；额度满后新建的是临时场次，关闭软件会失去未保存修改。先手动删除一个旧场次，再点击“保存当前场次”。不会自动覆盖最早场次。

删除的场次文件保留在项目内 `trash/` 备份中。切换临时场次前会要求明确放弃或先保存。旧 Pro 工程即使超过三场也不自动裁剪，移除授权不会删除工程；Lite 只限制继续保存新的超额场次。空间颜色分区和 Camera Take 均不算场次。

已有单场工程自动兼容。一个外部 `.blend` 若含多个 Blender Scene，本版会明确拒绝导入，避免只读第一场造成误解；可先在 Blender 分别整理为单场文件，自动拆分导入尚未实现。

## 手柄和官方体验

双摇杆、升降、俯仰、焦距映射沿用既有控制。Lite 可以直接在正式场景预览；点录制时需要 Pro。也不能先开始手动录制，再用手柄插入运镜。关闭手柄后可继续触控、体感或键盘录制。

授权面板的“官方场景 · 手柄试录”打开独立 Blender 体验窗口，使用固定室内示例与临时目录，不导入、修改或保存正式工程，也不运行 Blender MCP。关闭体验窗口即可返回原项目，试录不作为正式项目导出。PS5 仅标准映射与合成测试，未完成 DualSense 实机验收；iPhone/Windows 手柄实机验收也需分别验证。

## 导出与授权文件

镜头和俯视各自 1280×720，空间说明 1920×1080；合并视频 1920×2160，上下内容各 16:9。Lite 的每条可下载视频与说明图均加水印，JSON/TXT 参考文件另带 Preview 标识。Pro 沿用干净导出，不额外重编码。

授权保存于 macOS `~/Library/Application Support/DKYJ Director/license.json`，Windows `%LOCALAPPDATA%/DKYJ Director/license.json`。不会跟随 `.blend` 或工程备份传播。界面不显示完整码；移除只删本机授权，原码可再次使用，不是远程作废。
