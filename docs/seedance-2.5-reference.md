发布前复核：官方发布说明可正常读取，其白模参考章节说明使用无贴图 3D 模型表达空间结构、角色姿态、运动路径和摄影机角度。飞书手册本次抓取失败，保留此前已核对的链接与摘要，不把本次失败标为重新验证通过。名称为 **Seedance 2.5**。本仓库与 ByteDance／即梦无官方隶属关系。

手册区分粗白模与细白模。粗白模侧重机位、走位、节奏和动态信息，需要说清几何体／颜色对应的角色，以及最终场景和外观。对于带四肢或翅膀的粗模，建议完整交代动作顺序，并倾向使用没有这些细节的代理模型。细白模重在材质与光影的重新渲染，手册明确要求去掉轨迹、坐标与相机锥体等干扰。

本工具据此提供：

- **纯镜头 MP4**：真实摄影机输出，不含空间编号、尺寸线、摄影机模型或网页界面；勾选「简化人物」可将本示例的四肢隐藏，保留色块人物的位移、朝向、头部姿态。
- **空间总览 MP4／说明图 PNG**：清楚标出空间颜色、近似尺寸、摄影机朝向与路径。作为辅助空间说明，不作为最终成片的构图。俯视机位的轻微跟随是观察用途。
- **空间＋镜头 MP4**：便于人审核同步关系；不要求模型必须从这种拼版生成视频。
- **AI 参考说明 TXT**：导出时自动列出颜色对应关系、空间说明、相对本段录制开始的动作时间，以及明确的素材分工。
- **空间数据 JSON**：给人工或程序处理，包含坐标系、单位、帧范围、摄影机位置、旋转、焦距和动作元数据；不宣称即梦支持把 JSON 当视频参考上传。

船舱／甲板分成两个空间，同一物理空间不再按家具或人物位置另分颜色。露天甲板不显示虚构的室内净高。飞机使用固定翼描述，提示词说明机翼保持刚性、螺旋桨旋转。

尺寸线、俯视图版式、H.264 / 1280×720 输出和本套导出文件，是本工具的实现选择，并非官方强制格式。最终模型是否完全遵循运镜与布局，需要在实际生成中确认。
