第一次使用？安装 Blender 与连接 Agent

电脑支持 macOS（Safari）与 Windows（Edge）；手机仅支持 iPhone Safari。先完成电脑安装，再用手机打开同一 Wi-Fi 下的配对链接。

  1. 下载 Blender（官网）↗，Mac 选 Apple Silicon 安装到 Applications，Windows 选 Windows x64；另安装 Python 3.11+ ↗。
  2. 完整解压对应系统的安装包：Mac 运行 python3 scripts/setup.py，再双击 Launch DKYJ Director.command；Windows 双击 Install DKYJ Director.cmd，再双击 Launch DKYJ Director.cmd。该脚本安装导演台，不会替你安装 Blender MCP。
  3. AI 制作场景：按 Blender MCP 安装说明 ↗ 安装 uv；运行 uvx blender-mcp install-addon。在 Blender 偏好设置启用 MCP for Blender，3D 视图按 N，在 MCP 面板启动服务。
  4. Agent 侧配置 uvx blender-mcp；另外运行 .venv/bin/python -m pip install -r requirements-agent.txt 和 python3 scripts/agent_config.py，Windows 将 Python 命令换成 .venv\Scripts\python.exe（安装依赖用此路径替代 .venv/bin/python，生成配置也用此路径替代 python3），把输出的 DKYJ 配置加入同一个 Agent。完整配置见仓库 docs/agent-setup.md。
  5. 先让 Agent 读取 Blender 当前场景验证，再回答右侧四个问题；提交后在 Agent 对话中说“执行下一个 DKYJ 创作任务”。

手动预演不需要 MCP；AI 建模需两个服务都连接。手机体感需要 HTTPS、本人信任本地证书并允许 Safari 动作权限。
