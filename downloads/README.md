# Installation bundles / 安装包

These files are byte-for-byte mirrors of the 0.8.0-preview.6 Release assets.
If a new GitHub Release download returns 404, use the download buttons on the
[repository homepage](../README.md). Every bundle includes the corresponding
GPL application source. Check SHA-256 before installation.
